# 🤖 AI-Powered Solar Invoice Generator

A comprehensive FastAPI-based solar panel invoice generation system powered by Google Gemini AI. This system creates professional solar panel purchase inquiries and quotation requests, converting them to professional PDF documents.

## 🚀 Features

### Core Functionality
- **Gemini AI Integration**: Intelligent content generation using Google's Gemini AI
- **Professional PDF Generation**: High-quality PDF documents using ReportLab
- **Fallback System**: Local template generation when AI is unavailable
- **RESTful API**: Complete FastAPI endpoints for easy integration
- **Simplified Input**: Only essential parameters required

### AI-Powered Capabilities
- **Smart Content Generation**: Context-aware solar panel inquiries
- **Professional Language**: Business-appropriate communication tone
- **Comprehensive Quotations**: Detailed technical and commercial aspects
- **Customized Content**: Tailored to specific solar panel models and quantities
- **Error Handling**: Graceful fallback to local generation

### Technical Features
- **Real-time PDF Creation**: Instant PDF generation and download
- **Health Monitoring**: API health checks and status monitoring
- **Flexible Output**: Both JSON response and direct PDF download
- **Error Recovery**: Robust error handling and quota management

## 📋 System Requirements

- **Python**: 3.8 or higher
- **Operating System**: Windows/Linux/macOS
- **Memory**: 4GB RAM minimum, 8GB recommended
- **Storage**: 200MB for dependencies + document storage
- **Internet**: Required for Gemini AI API access
- **API Key**: Google Gemini AI API key required

## 🚀 Quick Start

### 1. Start the Server
```bash
python ai_invoice_server.py
```
Server runs on: `http://localhost:8002`

### 2. Access Services
- **Interactive Docs**: `http://localhost:8002/docs`
- **Health Check**: `http://localhost:8002/health`
- **Service Info**: `http://localhost:8002/`

### 3. Basic Usage
```python
import requests

# Generate AI-powered solar invoice
data = {
    "solar_panel_name": "Adani Solar 540W Mono PERC",
    "count": 12,
    "name": "Rajesh Kumar",
    "email": "rajesh.kumar@gmail.com",
    "phone_number": "+91-98765-43210",
    "address": "123 Solar Apartments, Bangalore, Karnataka - 560034"
}

# Get JSON response
response = requests.post("http://localhost:8002/generate-invoice", json=data)
result = response.json()

print(f"Invoice ID: {result['invoice_id']}")
print(f"Generated by: {result['generation_method']} {'🤖' if result['generation_method'] == 'ai' else '🏠'}")

# Download PDF directly
pdf_response = requests.post("http://localhost:8002/download-invoice-pdf", json=data)
with open("solar_invoice.pdf", "wb") as f:
    f.write(pdf_response.content)
```

## 📡 API Endpoints

### Main Invoice Generation
**POST** `/generate-invoice`

Generate solar panel purchase inquiry with AI-powered content.

#### Request Body:
```json
{
  "solar_panel_name": "Adani Solar 540W Mono PERC",
  "count": 12,
  "name": "Rajesh Kumar",
  "email": "rajesh.kumar@gmail.com",
  "phone_number": "+91-98765-43210",
  "address": "123 Solar Apartments, Bangalore, Karnataka - 560034"
}
```

#### Response:
```json
{
  "invoice_id": "AI-SOL-20251008-143052",
  "status": "success",
  "generated_content": "Subject: Solar Panel Purchase Inquiry...",
  "pdf_filename": "Solar_Invoice_AI-SOL-20251008-143052.pdf",
  "generation_method": "ai",
  "timestamp": "2025-10-08T14:30:52.123456"
}
```

### Direct PDF Download
**POST** `/download-invoice-pdf`

Generate and download PDF invoice directly.

**Request**: Same as above  
**Response**: PDF file download

### Utility Endpoints
- **GET** `/` - Service information and features
- **GET** `/health` - Health check and AI status
- **GET** `/docs` - Interactive API documentation

All parameters are required for comprehensive invoice generation.

## 🛠️ Troubleshooting

### Common Issues

1. **Gemini API Issues**
   - **Quota Exceeded**: System automatically falls back to local generation
   - **Invalid API Key**: Check API key configuration
   - **Connection Error**: Verify internet connectivity

2. **PDF Generation**
   - **ReportLab Errors**: Check dependencies installation
   - **File Permissions**: Ensure write permissions for temp files

3. **Server Issues**
   - **Port Conflict**: Change port in uvicorn.run()
   - **Import Errors**: Verify all dependencies installed

### Error Responses
```json
{
  "detail": "Error generating invoice: API quota exceeded",
  "status_code": 500
}
```

### Debugging Tips
- Check server logs for detailed error messages
- Use health endpoint to verify AI connectivity
- Test with simple parameters first
